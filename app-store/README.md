# App Store screenshots

These screenshots were captured from the iOS release build and uploaded to the English (U.S.) App Store product page on September 8, 2026.

| App Store Connect set | Folder | Size | Files |
| --- | --- | --- | --- |
| `APP_IPHONE_67` (Apple's API name for the highest-resolution iPhone set) | `screenshots/iphone-6.9` | `1320 x 2868` | 5 PNGs |
| `APP_IPAD_PRO_3GEN_129` (Apple's API name for the 13-inch iPad set) | `screenshots/ipad-13` | `2064 x 2752` | 5 PNGs |

Every image is RGB PNG without an alpha channel. Order is controlled by `store.config.json`.

Apple's current accepted sizes and formats are listed in the [screenshot specifications](https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/).
